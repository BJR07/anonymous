# For My Jaan ❤️

A responsive apology-and-love landing page made with plain HTML, CSS and JavaScript.

## Run it
1. Extract this folder.
2. Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.
3. Edit the text in `index.html` to make the apology more personal.

## Customize
- Main apology: edit the `.intro` paragraph in `index.html`.
- Letter text: edit the paragraphs inside `.letter`.
- Final pop-up: edit `.modal-message`.
- Colors, layout and animations: edit `style.css`.
- Button interactions: edit `script.js`.

This is a static site: it does not collect or send any information.
